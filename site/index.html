How it works

      
No servers and no image code. Cloudinary does the heavy lifting, from upload to the last byte on a phone.

    

    

      
Upload
The image goes straight from the browser to the Cloudinary Upload API through an unsigned preset. No secret ever reaches the page.
POST /v1_1/<cloud>/image/upload

      
Transform
Every version is a URL. Cloudinary renders it at the edge on first request: simulations, stripes, greyscale, contrast.
e_simulate_colorblind:deuteranopia

      
Deliver
f_auto and q_auto send each device the lightest format it can open, then the CDN caches it worldwide.
w_480,c_limit/f_auto,q_auto:eco

      
Measure
The browser reads the real bytes and pixels Cloudinary returns, to size every file and score the image.
Access-Control-Allow-Origin: *

      
Share
Links, a zip of every version, paste-ready HTML and a QR code for the printed poster.
e_assist_colorblind:40/e_grayscale

    

  


  
  

    

      

        
Notices are for everyone

      

      

      

        
Why I built this
Public notices exist to keep people safe. Too many are designed for one kind of reader: perfect colour vision, a fast connection, a big screen.

        
Free and open
A clinic, a school or a local council can check a notice and fix it in a minute, without a designer. Every fix is a link anyone can share.
