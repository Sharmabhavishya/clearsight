Under the hood

        
How it works.

        
No servers. No image code. Cloudinary does the heavy lifting.

      

      

        
Upload
Your image goes straight from the browser to the Cloudinary Upload API with an unsigned preset. Your secret key never leaves Cloudinary.

        
Transform
Every version is a URL. Cloudinary renders it at the edge on first request and caches it on its global CDN.

        
Share
Links, code, a zip and a QR code. f_auto and q_auto send each device the lightest format it supports.
